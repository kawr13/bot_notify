# Журнал изменений

## v1.0 — 2026-10-28 — мост GLPI → Битрикс24 работает

Собрано: `dist\BotNotifyDesktop.exe` (один файл, рядом нужен `.env`).

### Что умеет

1. **Новые заявки.** Оператор видит заявку в окне «Заявки GLPI», выбирает
   исполнителя из всего списка GLPI и жмёт «Отправить в чат»: сообщение уходит
   в Битрикс24, а исполнитель сохраняется в GLPI.
2. **Актуализация.** Кнопка «Актуализировать сейчас» прогоняет активные
   заявки наших сотрудников **по одной**, с паузой `GLPI_REFRESH_PACE` секунд
   между сообщениями. Повторное нажатие предлагает остановить.

Ничего само в чат не пишется: ни таймеров, ни автоотправки новых заявок —
только две кнопки.

### Починено в этом заходе

| Симптом | Настоящая причина |
|---|---|
| «Назначенный не добавляется» | GLPI 11 принимает актёров полем `_actors` (JSON), а не `_users_id_assign[...]`: старые поля только добавляют, удалить никого не могут |
| «Не применилось», хотя применилось | клиент перечитывал заявку из `_tabs_cache` (30 с) — то есть видел состояние ДО правки |
| «Назначенные сейчас» ничего не делали | кнопка была проткнута к `_load_current` (обновить список), а не к записи в GLPI |
| «Отправить в чат» ничего не делала | исключение в `_drain()` рвало цикл `after(250)` — очередь вставала навсегда, `_busy` не сбрасывался |
| «Сначала выбери заявку» на открытой заявке | `list_var.set()` пересобирает `Listbox` и снимает выделение, а выбор читался из `curselection()` |
| «Открыть в браузере» вешало окно | `webbrowser.open()` на Windows запускает браузер и ждёт его — из главного потока Tkinter |
| Требовало выбирать исполнителя заново | в поле лежала строка «Иванов · Первая линия», не совпадающая ни с одним пунктом |

### Ключевые решения (подробности — `docs/glpi-bridge.md`)

- REST к GLPI нет (Legacy отключён, HLAPI требует OAuth) — работает HTML-сессия:
  вход, `common.tabs.php` на карточку, `actors.php` на кандидатов.
- `glpilist_limit=60` — список заявок одним запросом за ~0.7 с; детали заявки
  докачиваются лениво, только на выбранную.
- Актёры пишутся одним полем `_actors`, семантика — замена списка целиком.
- Диалог Битрикс24: личный — `81`, групповой — `chat7018` (префикс `chat`
  обязателен, иначе «Указанный чат не существует»).
- Ссылки открывает `web_open.open_url()` → `os.startfile`, не `webbrowser`.

### Известные ограничения

- `@упоминание` через `[USER=81]@Имя[/USER]` на этой коробке выводится
  текстом, без кликабельного выделения.
- Поток писем (IMAP → VK) живёт по-прежнему и шлёт сам — решение о нём не
  принято.
- `.env` с секретами выведен из-под git (`git rm --cached`), шаблон —
  `.env.example`.
